HOSPITAL MANAGEMENT SYSTEM_____________
Project Report
________________________________________
ABSTRACT
The Hospital Management System (HMS) is a web-based application developed to simplify and digitalize the management activities of a hospital. The main objective of this project is to reduce manual paperwork, improve hospital workflow, maintain patient records efficiently, and provide a clean and centralized management platform for administrators.
The system helps manage patient records, doctor information, appointments, laboratory reports, pharmacy inventory, billing, and hospital analytics through a modern admin dashboard. The project provides a professional ERP-style interface where hospital administration tasks can be handled smoothly and efficiently.
The Hospital Management System is developed using web technologies such as HTML, CSS, JavaScript, Bootstrap, and Django framework with database integration. The system is designed with a modern responsive dashboard containing collapsible sidebar navigation, statistics cards, appointment management, patient management, doctor management, and analytics visualization.
The project improves hospital operational efficiency, minimizes data redundancy, reduces paperwork, and provides quick access to medical information.

INTRODUCTION
In modern healthcare environments, maintaining patient records manually becomes difficult, time-consuming, and error-prone. Hospitals require efficient systems to handle appointments, patient data, doctor schedules, laboratory reports, billing, and medicine inventory.
The Hospital Management System is designed to automate and simplify these operations through a centralized web-based platform. The system allows administrators to manage hospital activities digitally and maintain records securely.
This project focuses on providing:
•	Easy patient registration and management
•	Doctor management and scheduling
•	Appointment handling
•	Laboratory report management
•	Pharmacy inventory maintenance
•	Billing management
•	Hospital analytics dashboard
•	Bed and ward management
The application uses a clean and modern user interface similar to professional ERP systems, making it easy to use and visually attractive.
